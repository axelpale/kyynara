# kyynara 🌤️

This is a single-page app that gathers local information services related to Kyynärä, Letku, Tammela, Finland.

See the app at [kyynara.akselipalen.com](https://kyynara.akselipalen.com)

## Development

Local development may need to run on a local server to allow browsers to fetch data from external URLs.

Run the server:

```
$ python3 -m http.server 8000
```

And browse to [http://localhost:8000/](http://localhost:8000/).
